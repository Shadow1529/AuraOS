# 🌌 AuraOS

> A high-performance, glassmorphic Web Operating System UI built with vanilla HTML5, CSS3, and JavaScript. Inspired by the best design elements of macOS and Windows 11.

![AuraOS Preview](https://images.unsplash.com/photo-1618005182384-a83a8bd57fbe?q=80&w=1200&auto=format&fit=crop)

## ✨ Features

- **🔒 Secure Lock Screen & Authentication**: Password-protected entry system with modern frosted glass backdrop blur and live status-bar indicators.
- **🪟 Advanced Window Management**: Fully interactive, draggable windows with bring-to-front layering, minimization, fullscreen maximization, and window controls.
- **📊 Live Task Manager**: Real-time simulated CPU/RAM utilization meters, process list monitoring, and dynamic "End Task" process controls.
- **🕹️ Built-in Arcade Game Center**: Fully playable retro **Snake Arcade** game built directly into a desktop window with high-score tracking.
- **📝 Persistent Notepad**: Instant markdown-friendly text editor with local storage auto-save.
- **⚙️ Dynamic System Settings**: Interactive wallpaper switcher, hardware acceleration toggles, and theme customization.
- **🚀 Zero Dependencies**: Built completely with vanilla web technologies—no heavy frameworks or build tools required.

---

## 🛠️ Built With

- **HTML5** - Semantic structure and canvas rendering
- **CSS3** - Glassmorphism, CSS Grid, Flexbox, and smooth animations
- **JavaScript (ES6+)** - Window state management, game loops, and DOM manipulation
- **FontAwesome** - Modern UI iconography
