# 🌌 AuraOS v2.0

> A responsive, high-performance Web Operating System UI supporting both desktop and touch devices (iPad/Mobile). Inspired by modern glassmorphic designs from macOS and Windows 11.

---

## ✨ Features

- **📱 Fully Responsive & Touch-Optimized**: Designed for desktop screens, iPads, tablets, and mobile devices with touch gesture support.
- **🔒 Lock Screen & Authentication**: Secure lock screen with user login, password authentication, and status indicators.
- **🪟 Interactive Window Manager**: Draggable, minimizable, maximizable, and closable windows with active z-index stacking.
- **📁 File Explorer**: Navigate directories, inspect files, and interact with virtual storage.
- **💻 Terminal Shell**: Interactive CLI supporting custom commands (`help`, `ls`, `clear`, `neofetch`, `date`, `whoami`, `echo`).
- **🧮 Calculator**: Full mathematical calculation app with a sleek interface.
- **🕹️ Retro Arcade Game**: Built-in Snake game with touch and keyboard controls plus high-score persistence.
- **📝 Persistent Notepad**: Notepad editor with real-time automatic `localStorage` synchronization.
- **⚙️ Control Center & Settings**: Quick toggles for Wi-Fi, Bluetooth, volume, screen brightness, and custom wallpaper selection.
